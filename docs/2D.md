# 2D videos

A 2D episode is drawn in code: you write the script, a free offline voice (Kokoro) reads it, every word is timed,
and the episode's `scene.js` draws each frame on a 1080×1920 canvas in a headless browser, with big word-by-word
captions on top. The sound, the encode, the cover, the captions for each platform, QA and shipping are the same
as for a 3D episode (`docs/PIPELINE.md`).

`examples/demo_2d_penny/` is the reference: "A million dollars now, or a penny doubled for 30 days?" (about 66 s).
`reelforge new-episode <slug>` copies it for a 2D channel.

## The steps

```
.venv\Scripts\python -m studio new-episode penny_doubling           (episodes\epNN_penny_doubling\)
.venv\Scripts\python pipeline\make_episode.py episodes\<id> --steps build                (voice the script, ~15 s)
.venv\Scripts\python pipeline\make_episode.py episodes\<id> --steps stills --stills 1,8,15,22,31,40,48,56,62
.venv\Scripts\python pipeline\make_episode.py episodes\<id> --steps render               (every frame, 1-3 min)
.venv\Scripts\python pipeline\make_episode.py episodes\<id> --steps post                 (sound, video, cover, QA)
   (look at build\qa\report.md, the contact sheets and the video; write build\qa\review.md, then:)
.venv\Scripts\python pipeline\make_episode.py episodes\<id> --steps ship
```

| Step | 2D | Output |
|---|---|---|
| `build` | speaks every beat of `script` with Kokoro, times every word, places the beats one after another | `build/voice/voice.wav`, `build/voice/timeline.json`, `build/series.json` |
| `stills` | draws the chosen seconds, captions included | `build/stills/s_####.jpg` |
| `render` | draws every frame; draws them all again by itself when `scene.js`, the script or the captions change (not when a picture the scene loads changed: run it with `--rerender all` then) | `build/frames/f_####.jpg` |
| `cover` | draws the cover's moment without captions, then the cover words over it (or the frame as it is: `"plain": true`) | `final/cover.jpg` |
| `audio` | the voice on top, the beds ducked under it while it speaks, the hits on their beats | `build/audio.wav`, `build/mix.json` |

Voice first, then draw: the scene keys off the beats' times, which only the voice step knows. The voice step
prints each beat's start and end. Each beat is cached (`build/voice/cache/`), so changing one line re-speaks only
that line. QA and the render stop if the script changed after the voice step.

## episode.json (2D keys)

```json
{
  "id": "ep07_penny", "engine": "2d", "title": "A million dollars now, or a penny doubled for 30 days?",
  "fps": 30, "duration": "auto", "scene": "scene.js",
  "voice": {"voice": "am_michael", "speed": 1.08, "start": 0.25, "gap": 0.16, "tail": 1.6},
  "script": [
    {"id": "hook", "say": "Would you take one million dollars right now, or a penny that doubles every day?"},
    {"id": "d10", "say": "Day ten. Five dollars and twelve cents.", "show": "Day 10: $5.12."},
    {"id": "final", "say": "Five million dollars.", "gap": 0.5}
  ],
  "captions": {"y": 1250},
  "audio": {
    "mixer": "samples",
    "voice": {"gain_db": 0, "duck_db": -8, "bed_db": -17},
    "beds": [{"sound": "pulse_bed", "from": 0, "to": 70, "gain": 0.9}],
    "cue_hits": [{"sound": "kaching", "at": "d10"}, {"sound": "rise_tone", "at": "final", "align": "end"}]
  },
  "cta": {"start": -2.6, "end": -0.3, "text": "FOLLOW FOR MORE", "sub": "Comment your pick", "y": 1560},
  "cover": {"time": 1.2, "plain": true},
  "hashtags": ["fyp", "money", "whatif"]
}
```

| Key | Meaning |
|---|---|
| `engine` | `"2d"` (a 3D episode leaves it out, or says `"blender"`) |
| `duration` | `"auto"`: the voice's end plus `voice.tail`, at least the channel's shortest length. Or a number: the voice step stops if the voice runs past it |
| `scene` | the drawing code, `scene.js` by default (paths in it are from the episode folder) |
| `voice` | `voice` (any Kokoro voice: `af_heart`, `af_bella`, `am_michael`, `am_fenrir`, `am_puck`, `bf_emma`, `bm_george`, ...; names starting with `b` are British), `speed` (0.5-2, about 1.0-1.15 sounds natural), `start` (seconds before the first beat), `gap` (between beats), `tail` (after the last), `lang` (`en-us` / `en-gb`, from the voice by default) |
| `script` | the beats, in order. `say`: what's spoken. `id`: a name the scene and the sound cues use. `show`: the caption text when it should differ from what's said (digits, symbols). `gap`: this beat's pause before it. `at`: start no earlier than this second. `hold`: silence after it. A beat with no `say` and a `hold` is a silent visual moment |
| `captions` | `show` (false: none), `y` (centre of the caption, 1240 by default), `size` (92), `color`, `highlight` (the spoken word, `#FFD60A`), `stroke`, `max_words` (3 per caption), `max_chars` (18), `upper` (true), `pop` (true) |
| `audio.voice` | `gain_db` (the voice against its -20 dBFS reference), `duck_db` (how far the beds dip while it speaks, -9 by default; the hits dip half as much), `bed_db` (negative: pins everything else that many dB under the reference, -17 is 17 dB under, so `gain_db` moves the voice against it) |
| `audio.cue_hits` | hits on beats: `"at": "<beat id>"` (its start) or `"<id>:end"`, plus `offset`; everything else as `hits` |
| `cta`, `title_card`, `cover.time` | seconds, a beat id (`"d10"`, `"d10:end"`), or negative seconds from the end |

Every other key (`hashtags`, `cover`, `qa`, `beds`, `hits`, `rewind`, `loop_to_start`...) works as in
`docs/PIPELINE.md`. Generated beds for voiced videos: `pulse_bed` (light, 120 bpm) and `calm_bed` (a soft pad); tonal
accents: `bubble_pop`, `rise_tone`, `coins`, `kaching`, `shimmer`.

## scene.js

```js
scene({
  assets: {logo: "assets/logo.png"},     // optional images, loaded before the first frame (rf.img.logo)
  setup(rf) { /* once: work out times from the beats, build lists */ },
  draw(g, t, rf) {                       // every frame: g is the canvas's 2D context, t is seconds
    rf.bg(g, ["#1B2A6B", "#0F7C7A"]);
    const s = rf.pop(t, rf.cue("d10"));   // pops in when the beat "d10" starts
    if (s > 0) { g.save(); g.translate(540, 800); g.scale(s, s); rf.circle(g, 0, 0, 150, {fill: "#FFD60A", stroke: "#000", lw: 10}); g.restore(); }
    rf.hud(g, {label: "DAY 10", value: rf.money(5.12)});
  },
});
```

**A scene is a pure function of `t`:** everything on screen is worked out from the time, never from the frame
before. Frames are drawn in any order (stills, a resumed render), and randomness comes from `rf.rand(seed)`, never
`Math.random()`. The canvas is reset to black before each frame and the captions are drawn after `draw`.
Plain canvas calls work everywhere; `rf` saves typing:

| Helper | What it does |
|---|---|
| `rf.W`, `rf.H`, `rf.fps`, `rf.duration`, `rf.title` | 1080, 1920, 30, the video's length, the title |
| `rf.cue(id, "start"/"end")` | when a beat starts (or ends) |
| `rf.beat(t)` | the beat being spoken: `{i, id, say, start, end, t (seconds into it), p (0-1 through it)}` |
| `rf.word("million", n)` | when a caption word is said (the n-th time), or null |
| `rf.beats`, `rf.words` | the whole timeline |
| `rf.map(t, t0, t1, a, b, ease)` | a value from a to b between t0 and t1 (eased; held outside) |
| `rf.tween(t, [[t0, v0], [t1, v1], ...], ease)` | a value through keyframes (numbers or arrays) |
| `rf.pop(t, at, len)` | 0 before `at`, then an overshooting scale to 1: things appearing |
| `rf.pulse(t, at, len)` | 0 -> 1 -> 0 around a moment |
| `rf.wave(t, hz, amp)`, `rf.noise(x, seed)` | bobbing and drift |
| `rf.ease.*` | `linear in out inOut in3 out3 inOut3 inExpo outExpo outBack outElastic outBounce` |
| `rf.lerp`, `rf.clamp`, `rf.inv`, `rf.smooth`, `rf.rand(seed)` | maths; `rand(seed)()` gives the same numbers every frame |
| `rf.circle`, `rf.ellipse`, `rf.rect`, `rf.box` (by its centre), `rf.poly`, `rf.line`, `rf.arrow`, `rf.star`, `rf.blob` | shapes, each with `{fill, stroke, lw, r (corner radius), shadow: {color, blur, x, y}}` |
| `rf.text(g, str, x, y, {size, weight, font, color, stroke, lw, align, maxWidth, shadow, spacing})` | text with a thick outline; `font`: `heavy` (the captions' font), `sans`, `serif`, `mono`; `maxWidth` shrinks it to fit |
| `rf.measure(g, str, opts)` | a text's width |
| `rf.bg(g, colour or [colours])`, `rf.gradient`, `rf.radial`, `rf.mix(a, b, p)`, `rf.shade(c, ±p)`, `rf.rgba(c, a)` | colour |
| `rf.rays(g, x, y, t)`, `rf.vignette(g)`, `rf.flash(g, amount)`, `rf.burst(g, t, at, x, y, opts)` | effects: sunburst, dark edges, a flash, confetti/sparks/coins from a point |
| `rf.camera(g, {x, y, zoom, rot, shake, t})` | look at a point of a world drawn at full size; `g.restore()` after |
| `rf.hud(g, {label, value, sub, y, color})` | a big counter at the top, no box |
| `rf.num(v, d)`, `rf.money(v, d)`, `rf.short(v)` | `1,234,567`, `$5,368,709.12`, `5.4M` |
| `rf.image(g, rf.img.name, x, y, w)`, `rf.emoji(g, "🚀", x, y, size)` | images and emoji (emoji look different on every system: draw what matters) |

## Making it great

- **Frame 1 is the cover:** the subject big, the question clear, nothing still popping in.
- **Something new every 2-3 s,** timed to the voice: each beat brings a new object, number or move, and the framing
  changes at least every ~8 s. The last 20 s are the biggest (bigger numbers, shake, flashes, bursts).
- **Draw it, don't describe it:** every number the voice says is on screen as it's said (a counter, a tag, a bar),
  and every thing it names is drawn.
- **Leave the caption band clear** (about y 1150-1350), and keep anything important out of the bottom 380 px and the
  right 140 px, where the apps put their buttons and caption.
- **Bold and readable on a phone:** thick dark outlines, big shapes, few colours per scene, text at least 44 px.
- **Look at the stills, then the video.** Stills take seconds: iterate on them until every one is good, then render.

## Errors

A mistake in `scene.js` stops the step with the browser's message and the time it was drawing, e.g.
`scene.js failed drawing 12.40 s: ReferenceError: coinn is not defined`. `rf.cue("x")` with no beat `"x"` says so.
The browser is the one ReelForge uses for stats (Edge on Windows; Chrome, Edge or Playwright's Chromium elsewhere).
